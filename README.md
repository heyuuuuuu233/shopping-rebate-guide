# 个人官方返佣申请指南

一步步申请淘宝联盟、多多进宝、京东联盟，以及了解美团、淘宝闪购的个人手机推广入口。教程区分手机手动推广、API／MCP 接入、实际返佣和提现到账。

更新日期：**2026-10-16**。菜单、账号资格和活动规则以本人当前官方页面为准。

## 从哪里开始

- **普通用户**：下载 [15 页 PDF 操作手册](output/pdf/个人返佣申请操作手册.pdf)，按平台逐步操作。每步包含操作、完成标志及不同页面的处理方法。
- **协助接入的 AI／开发者**：阅读 [完整申请与接口接入教程](docs/APPLY-GUIDE.md)，按阶段检查已有账号、推广位、应用和具体接口权限。
- **只想手动取链**：先完成个人推广流程，能在官方入口生成自己的推广内容即可。开发者应用和接口申请属于可选进阶。

## 手册涵盖什么

1. 准备本人账号、真实资料，分清推广账号、媒体、推广位和应用。
2. 淘宝、拼多多、京东普通购物的个人手动推广步骤。
3. 需要 AI 自动化时，再按需申请应用与具体 API 权限。
4. 美团、淘宝闪购的官方手机入口，以及企业申请分支的停点。
5. 京东外卖／秒送的活动核对方法。
6. 人与 AI 的交接、完成检查、常见错误及官方入口。

## 使用原则

- 使用自己的官方联盟账号、真实资料及推广身份；不要复制第三方的推广位或凭据。
- 通过官网确认公众号、小程序和扫码入口；密码、验证码、证件、协议及秘密凭据由本人处理。
- 优惠券、预估佣金、实际计佣、佣金结算和提现到账分别核对，不保证每个商品或自购订单都有佣金。
- 已有真实订单时再查归属和结算，不需要为了测试接口而购买。
- 权限审核、风控或企业资质要求由平台决定；不伪造公司、网站和流量，也不绕过限制。

本仓库分享操作教程。正文提及的工程专用脚本用于解释既有接入经验，本仓库没有随附可安装的 MCP 服务。正文及配套 PDF 不包含私人账号资料、个人推广位、密钥或带佣金归属的专属推广链接。
